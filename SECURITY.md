# Security policy

Please do not open a public issue for a vulnerability or privacy failure. Use GitHub's private vulnerability reporting feature for the repository. Include affected versions, reproduction steps, impact, browser/OS, and any evidence that media or metadata crossed the documented local-only boundary.

Do not include real private recordings, credentials or personal information. Use synthetic media for proofs of concept.

Maintainers will acknowledge a report, investigate it privately, prepare a fix and coordinate disclosure. There is currently no paid bug bounty. Supported security updates target the latest `main` release.
